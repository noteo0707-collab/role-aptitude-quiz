# 職種適性クイズ

## ローカルで開く

1. `index.html`、`style.css`、`app.js` の3ファイルを同じフォルダーに置きます。
2. `index.html` をダブルクリックしてブラウザーで開きます。
3. YES / NOで回答します。途中で戻ることも、最初からやり直すこともできます。
4. 最後に選ばれた職種を確認し、「結果をコピー」で共有用にコピーできます。

このアプリは静的なWebページです。サーバーやデータベースは使わず、回答を外部へ送信しません。

## 公開

公開するときは、この3ファイルを同じGitHubリポジトリにアップロードし、GitHub Pagesを有効にします。公開先のリポジトリを決めたら、画面を見ながら設定を案内できます。
